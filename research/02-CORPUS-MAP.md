## SWE-bench

Task record fields: .

The world reproduces the *shape* - an issue, a change, tests that must pass - via
`repo_files`, `code_edit` pull-request changes and a CI pipeline with build, unit,
integration and regression stages. It does **not** execute real test suites against
real repositories, so SWE-bench-style tasks here are PARTIAL by construction: the
workflow is faithful, the substrate is simulated.
